# sprint-9-project
Репозиторий для разработки проекта 9-го спринта.

### КОММЕНТАРИЙ К 1 ВЕРСИИ ПРОЕКТА:
Во время написания проекта случилась авария в дата-центре, из-за чего не удалось проверить структуру поступающих данных в Kafka, Postgres и Redis. Все три сервиса (STG, DDS, CDM) задеплоены в K8s — поды Running. Готов исправить замечания во второй версии.

### Часть 1 - STG-сервис.
Принимает данные из кафки, добавляет к ним имена и названия из Redis и сохраняет для нужд DDS.

### Часть 2 - DDS-сервис.
Принимает данные из STG, раскидывает их по хабам, линкам и сателлитам, а также создаёт условия для подсчёта витринных данных.
Образы: cr.yandex/crpe8eodj94r7ltgfo1g

### Часть 3 - CDM-сервис.
Принимает данные из DDS, строит витрины user_product_counters и user_category_counters.
